SmartBudget v1.1

1. Deschide aplicatia pe telefon si foloseste Setari > Export JSON pentru backup.
2. In GitHub, repository smartbudget > Add file > Upload files.
3. Incarca cele sase fisiere de aplicatie din arhiva, fara README (optional).
4. Confirma suprascrierea fisierelor vechi prin Commit changes.
5. Dupa publicare, redeschide aplicatia si verifica versiunile si datele.

IMPORTANT: nu incarca niciodata backupul JSON cu date personale in repository public.
